# 📓 Todo List

React로 만든 할 일 관리 앱이에요. Git 협업을 연습하며 함께 만들었어요.

## 🔗 배포 주소
https://study-eight-ebon.vercel.app

## ✨ 주요 기능
- 가짜 로그인과 페이지 보호 (연습용)
- 할 일 추가 / 수정 / 삭제 / 완료 체크
- 필터 (전체 / 진행 중 / 완료)
- 마감일 설정 (기한이 지나면 빨간색 표시)
- 다크 모드
- 새로고침해도 데이터 유지 (localStorage)

## 🛠 사용 기술
React, Vite, react-router-dom

## 🚀 실행 방법
```bash
npm install
npm run dev
```
